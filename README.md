# Classroom PLus

ระบบห้องเรียนออนไลน์สำหรับครูและนักเรียน ทำงานบน **Google Apps Script** โดยใช้ **Google Sheets** เป็นฐานข้อมูล และ **Google Drive** เก็บไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | Backend ทั้งหมด (API, สิทธิ์, ฐานข้อมูล, Drive, แจ้งเตือน, สำรองข้อมูล) |
| `Index.html` | หน้าเว็บทั้งหมด (SPA: HTML + CSS + JS ในไฟล์เดียว) |
| `appsscript.json` | Manifest (เขตเวลา, สิทธิ์ OAuth, การตั้งค่า Web App) |
| `tools/` | สำหรับนักพัฒนาเท่านั้น — ไม่ต้องคัดลอกไปที่ Apps Script |

## ติดตั้ง (ประมาณ 10 นาที)

1. เปิด https://script.google.com → **โครงการใหม่** ตั้งชื่อ `Classroom PLus`
2. **ตั้งค่าโครงการ** (รูปเฟือง) → ติ๊ก *แสดงไฟล์ Manifest "appsscript.json" ในตัวแก้ไข*
3. ในตัวแก้ไข
   - เปิด `Code.gs` → ลบโค้ดเดิม → วางเนื้อหา `Code.gs` จาก repo
   - เปิด `appsscript.json` → วางเนื้อหาจาก repo
   - กด **+ → HTML** ตั้งชื่อ `Index` (ไม่ต้องพิมพ์ .html) → วางเนื้อหา `Index.html`
   - กด 💾 บันทึก
4. เลือกฟังก์ชัน `setup` ที่แถบด้านบน → **เรียกใช้** → อนุญาตสิทธิ์ (บัญชีนี้ต้องมีสิทธิ์ *แก้ไข* Sheet และ Drive ข้างบน)
   ระบบจะสร้างชีต 13 แผ่น + หัวคอลัมน์ + บัญชี admin + ข้อมูลตัวอย่าง (ไม่ลบข้อมูลเดิม)
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด ทำให้ใช้งานได้ → คัดลอก URL ที่ลงท้าย `/exec` — นี่คือหน้าเว็บที่ใช้งานจริง
6. เข้าสู่ระบบด้วย `admin / admin123` → เปลี่ยนรหัสผ่าน → **ตั้งค่าระบบ → สำรอง/กู้คืน → เปิดงานอัตโนมัติรายวัน**

> แก้โค้ดภายหลัง: ต้อง **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** หน้า `/exec` จึงจะอัปเดต

## ฟีเจอร์

**นักเรียน** ลงทะเบียน 3 ขั้นตอน (PDPA) · เข้าระบบด้วยรหัส 5 หลัก + วันเกิด · ลืมรหัส (ยืนยันชื่อ-สกุล + วันเกิด) · ดูบทเรียน/วิดีโอ (YouTube, Vimeo, Drive, MP4 — เล่นต่อจากจุดเดิม, ปรับความเร็ว, เต็มจอ) · ดาวน์โหลด/พรีวิวไฟล์ · ส่งงาน (ไฟล์ลากวาง, ลิงก์ Drive, ข้อความ, บันทึกร่างอัตโนมัติ, แก้ไขก่อนหมดเวลา, ประวัติการแก้ไข) · ดูคะแนน/ความเห็นครู · ประกาศ (Infinite Scroll) · ค้นหา + ตัวกรอง · Dashboard ความคืบหน้า · แก้โปรไฟล์/รูป/รหัสของตนเอง

**ครู (Admin)** Dashboard + กราฟ (รีเฟรช 60 วิ) · จัดการผู้ใช้ (เพิ่ม/แก้/ลบ/อนุมัติ/ตั้ง-ถอด Admin/รีเซ็ตรหัส/นำเข้า-ส่งออก Excel) · ระดับชั้น ห้อง หมวดหมู่ · รายวิชา → หน่วย → บทเรียน (จัดลำดับ, วันเผยแพร่/ปิด, รูปปก, วิดีโอ, ไฟล์, ลิงก์) · มอบหมายงาน + ตรวจให้คะแนน · ประกาศ (ปักหมุด, รูป, ไฟล์, กลุ่มเป้าหมาย) · รายงาน 5 แบบ → Excel / CSV / PDF · สำรอง/กู้คืน · Audit Log · สลับโหมด Admin ↔ User · ตัวกรองเจ้าของข้อมูล

**ความปลอดภัย** รหัสผ่าน salt + SHA-256 ×300 · Token สุ่ม เก็บเฉพาะแฮช (Sheet + Cache) อายุ 8 ชม. / 30 วัน · ตรวจสิทธิ์ทุกคำสั่งฝั่ง Server · จำกัดการลองรหัสผิด · กัน Admin คนสุดท้าย/บัญชีที่ใช้อยู่ · Escape HTML ทุกจุด · กัน formula injection ใน Sheet · ตรวจชนิด/ขนาดไฟล์ · LockService กันเขียนชนกัน

## ข้อจำกัดที่ควรรู้

- **ขนาดไฟล์อัปโหลด 20 MB/ไฟล์** (`google.script.run` รับข้อมูลได้จำกัด) ไฟล์ใหญ่กว่านั้นให้อัปโหลดเข้า Google Drive แล้วแนบเป็นลิงก์ — 5 GB ผ่าน Apps Script โดยตรงทำไม่ได้
- ไฟล์ที่อัปโหลดถูกตั้งเป็น "ทุกคนที่มีลิงก์ดูได้" เพื่อให้นักเรียนเปิดได้ บาง Google Workspace ห้ามแชร์แบบนี้ → นักเรียนต้องล็อกอินบัญชีโรงเรียนจึงเปิดได้
- **LINE Notify ปิดบริการแล้ว** (31 มี.ค. 2568) จึงใช้ LINE Messaging API (broadcast ถึงผู้ติดตาม LINE OA)
- Web Notification ในหน้า Apps Script (iframe) บางเบราว์เซอร์ไม่อนุญาต — กระดิ่งในแอปยังทำงานเสมอ
- เล่นต่อจากจุดเดิม/ดูครบอัตโนมัติ ทำได้กับ YouTube และไฟล์ .mp4; Vimeo/Drive ใช้ปุ่ม "ทำเครื่องหมายว่าดูครบ"
- Google Sheets เหมาะกับโรงเรียนขนาดเล็ก–กลาง (หลักพันผู้ใช้); Apps Script ประมวลผลได้ ~30 คำสั่งพร้อมกัน
- รหัสนักเรียน 5 หลักเดาได้ง่าย จึงตั้งค่าเริ่มต้นให้ยืนยันวันเกิดด้วย (ปิดได้ใน ตั้งค่าระบบ → ระบบ)
- เปิดให้สมัครบัญชีครูเองและไม่ต้องอนุมัติเป็นค่าเริ่มต้นตามที่กำหนด — **แนะนำให้เปิด "ต้องให้ Admin อนุมัติ"** ทันทีหลังติดตั้ง
